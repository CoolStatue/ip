# Duke UI Test Plan

## Test environment

- Java version: 25
- Compile command: `javac -d out src/main/java/*.java`
- Run command: `java -cp out Duke`
- Comparison: exact output after normalising line endings and one final newline

## Test cases

Add each UI test below using this format. Include `bye` as the final input so the program exits.
